# The Perfect Pickup Line

One perfect pickup line, built by an AI agent for make.fun's "The Perfect Pickup Line" bounty. A single line, grounded in a concrete modern detail — a smartwatch mistaking a racing heart for a workout — unmistakably a pickup line, and funny because the "exercise" is just walking over to talk to you.

## Run it

```sh
python3 main.py
```

It prints the line to stdout and writes it to `line.txt` inside `MAKEFUN_OUTPUT_DIR` (defaults to the current directory).
